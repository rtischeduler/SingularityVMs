a2ping - 클라우드에서 온라인

이것은 Ubuntu Online, Fedora Online, Windows 온라인 에뮬레이터 또는 MAC OS 온라인 에뮬레이터와 같은 여러 무료 온라인 워크스테이션 중 하나를 사용하여 OnWorks 무료 호스팅 공급자에서 실행할 수 있는 a2ping 명령입니다.

우분투에서 실행 페도라에서 실행 Windows Sim에서 실행 MACOS Sim에서 실행

프로그램:

이름


a2ping.pl -- PS, EPS, PDF 및 기타 페이지 설명 간 변환
형식

개요


a2ping.pl [--]도움
a2ping.pl [--]의사
a2ping.pl [옵션]입력 파일> [[아웃포맷:] 결과물 파일]

기술


에이핑 많은 것을 변환하는 Perl로 작성된 UNIX 명령줄 유틸리티입니다.
래스터 이미지 및 벡터 그래픽 형식을 EPS 또는 PDF 및 기타 페이지로
설명 형식. 허용되는 입력 파일 형식은 PS(PostScript), EPS,
PDF, PNG, JPEG, TIFF, PNM, BMP, GIF, LBM, XPM, PCX, TGA. 허용된 출력
형식은 다음과 같습니다. EPS, PCL5, PDF, PDF1, PBM, PGM, PPM, PS, MarkedEPS, MarkedPS,
PNG, XWD, BMP, TIFF, JPEG, GIF, XPM. 에이핑 낮은 수준의 작업을 다음에게 위임합니다.
고스트스크립트(GS), PDF탑스 샘2p. 에이핑 동안 많은 결함을 수정
EPS를 EPS로 변환하므로 출력이 더 호환되고 더 좋습니다.
입력보다 임베딩 가능합니다.

"--below" 옵션이 없으면 0,0에서 시작하도록 보장됩니다.
동등 어구. "--below", "--hires" 및 "-v"가 권장되는 옵션입니다.

페이지 크기는 BoundingBox와 정확히 일치하도록 설정됩니다. 이것은 의미
Ghostscript가 렌더링할 때 결과를 자를 필요가 없으며 PDF
미디어박스가 맞습니다.

물론 경계 상자가 올바르지 않으면 문제가 있습니다. 먹이를 주면
젠장, 당신은 똥을 얻을. 그러나 당신은 공급할 수 있습니다 --bboxfrom=계산-gs ~에 대한 옵션
GS가 경계 상자를 다시 계산하도록 합니다.

입력 파일의 이름은 중요하지 않습니다 -- 에이핑 파일 형식 감지
파일의 처음 몇 바이트를 기반으로 합니다. 출력 파일의 이름이 중요합니다.
if 아웃포맷 명령줄에서 누락된 경우: 다음 확장자
출력 파일은 FileFormat(아웃포맷).

외부 프로그램


내부 파일 형식 a2ping.pl PS/EPS입니다. 읽는 모든 것이 먼저다
PS 또는 EPS로 변환한 다음 a2ping.pl, 다음으로 변환
출력 형식.

비 EPS PS 파일(및 EPS)의 경계 상자 및 기타 속성을 분석하려면
옵션이 있는 파일 --bboxfrom 이외의 =추측), GS가 사용됩니다. PS로 변환
EPS는 이 분석을 포함합니다.

PDF 파일을 작성하기 위해 GS가 사용됩니다.

PDF 파일을 읽으려면, PDF탑스 인사말 xpdf 패키지가 사용됩니다.

샘플링된 입력 형식은 PNG, JPEG, TIFF, PNM, BMP, GIF, LBM, XPM, PCX 및
TGA. 샘플링된 입력 형식을 읽으려면 샘2p 사용. 샘2p 래스터 이미지입니다
작성자가 C++로 작성한 변환기 a2ping.pl.

추가 출력 형식은 PNG, XWD, BMP, TIFF, JPEG, GIF 및 XPM입니다. 쓰기
추가 출력 형식, 샘2p 및 GS가 사용됩니다.

PNM 출력 형식은 PGM, PGM 및 PPM입니다. PNM 출력 형식을 작성하기 위해 GS는
익숙한.

팁 및 트릭


· 통화 -v 진행률 및 디버그 메시지를 볼 수 있는 옵션입니다.

· EPS에 잘못된 경계 상자가 포함되어 있으면 다음을 실행하여 수정할 수 있습니다.
"a2ping.pl -v --bboxfrom=compute-gs thefile.eps --"

· 지정할 수 있습니다 - as 입력 파일 stdin을 얻으려면 결과물 파일 도착
표준 출력. 이것은 PDF 파일(검색 가능해야 함)에도 작동합니다.
에이핑 자동으로 임시 파일에 복사합니다.

· 만약에 입력 파일 결과물 파일 동일합니다. 에이핑 복사 입력 파일 에
임시 위치 먼저. 그러나 이 사용은 다음과 같은 경우에만 권장됩니다.
경우에 따라 복원할 파일의 백업입니다. 에이핑 생산하지 않는다
원하는 결과.

· 지정하는 경우 -- as 결과물 파일, 다음과 같을 것입니다. 입력 파일.

· 에이핑 존중 --듀플렉스 GS는 그렇지 않지만 FileFormat PCL5의 경우.

· GS는 읽을 수 있지만 프린터는 읽을 수 없는 호환되지 않는 PS가 있는 경우
인쇄하려면 "a2ping.pl foo.ps PDF: - ⎪ a2ping.pl - PS: foo.ps"를 실행하세요.

· Win32(종종 확장자가 ".prn"인 경우가 많음)에서 가져온 PS가 있는 경우 실행하십시오.
을 통하여 에이핑. 해상도 변경 및 진행 텍스트가 제거됩니다.
터미널에 인쇄됨(혼동 gv(1) 및 일부 필터를 만듭니다.
인쇄 대기열이 잘못된 출력을 내보냄).

· 에이핑 앤티앨리어싱(--antialias=scale3no) 글리프 및 곡선의 경우
샘플링된 이미지를 내보냅니다(PGM 및 PPM과 같은 파일 형식). 이것은 향상
글리프의 가독성. =예 내부 안티앨리어싱을 수행하도록 GS에 지시합니다.
그러나 일반적으로 많이 개선되지 않습니다. =scale3no GS 내부 끄기
앤티앨리어싱, 하지만 모든 것을 3x3으로 크게 렌더링한 다음 크기를 조정합니다.
뒤로 물러나다. =scale3no 3x3 스케일링과 GS 내부를 모두 켭니다.
앤티 앨리어싱으로 인해 선이 더 두껍고 일반적으로 품질이 저하됩니다.

· PBM 파일을 생성할 때 일반적으로 앤티앨리어싱은 품질을 향상시키지 않으며,
따라서 기본적으로 꺼져 있습니다. 하지만 설정하면 --antialias=scale3no or
--안티앨리어스=scale3yes, GS는 PGM 파일을 렌더링하고 값은
--한계점 최종 PBM에서 흰색의 최소 강도를 결정합니다.

· 더 큰 샘플링된 출력 파일이 필요한 경우 더 크게 지정하십시오. --해결.
디폴트는 --해상도=72. 샘플링된 출력 파일이
정말 크면 지정해야 합니다. --AntiAlias=예 기본값 대신
--AntiAlias=scale3no 변환 속도를 높이기 위해.

MISC


· 입력 파일의 파일명이나 확장자에 의존하지 않습니다.

· EPS에서 PDF로 변환: 결함 등을 수정하고 gs -sDEVICE=pdfwrite를 호출합니다.

· EPS에서 EPS로 변환: 다양한 결함 수정, 이동(llx,lly)
(0,0), EPS 등의 시작 부분에서 바이너리 정크를 제거합니다.

· PDF에서 PDF로 변환: 파일을 그대로 유지

· PDF에서 EPS로 변환: pdftops -eps(xpdf 패키지의) 호출

· PS에서 EPS로 변환: 첫 번째 페이지만 유지, setpagedevice 등을 제거합니다.
