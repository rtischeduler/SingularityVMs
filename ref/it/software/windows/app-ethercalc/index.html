Wine è un livello di compatibilità Windows open source in grado di eseguire programmi Windows direttamente su qualsiasi desktop Linux. Essenzialmente, Wine sta cercando di re-implementare abbastanza Windows da zero in modo che possa eseguire tutte quelle applicazioni Windows senza effettivamente bisogno di Windows.

EtherCalc


DESCRIZIONE

EtherCalc è un foglio di calcolo open source basato sul Web che consente a più utenti di collaborare e lavorare in remoto e in tempo reale. Gli utenti possono modificare lo stesso foglio di calcolo contemporaneamente, con le modifiche che si riflettono immediatamente sullo schermo. Accetta varie formule matematiche e altre funzioni e supporta anche diverse direttive di formattazione del testo predefinite. Può essere utilizzato per qualsiasi cosa per cui avresti bisogno di un foglio di calcolo desktop: contabilità, inventario, pianificazione, gestione degli elenchi e molto altro ancora.

EtherCalc è il successore migliorato di SocialCalc, ottimizzato per l'editing simultaneo. È un'ottima alternativa open source ai fogli di Google, senza fastidiosi accessi o blocchi di modifica.



Caratteristiche

  • Modifica simultanea e multiutente di fogli di calcolo basati sul Web
  • Accetta numerose formule matematiche e altre funzioni, date e testo
  • Opzioni di formattazione del testo
  • Opzioni avanzate di modifica e formattazione (ad es. colori di testo/sfondo, ecc.)
  • Formattazione condizionale delle celle


Linguaggio di programmazione
